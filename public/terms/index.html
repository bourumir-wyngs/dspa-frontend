Access and acceptable use

This service is intended for professional usage within the research scope only. Do not supply any sensitive personal data.

The current level of confidentiality is "authorized ETHZ staff". The information you enter is not world-exposed, but some if it can be accessed by administrators with legitimate server login credentials. If you work with sensitive data, contact us to harden the confidentiality first.

Memory tool is equipped with a prompt injection filter. It may refuse to store memories classified as "potentially malicious" even when they actually may not be. While Copilot should also normally refuse to do anything illegitimate, never ask it for such things during normal operation.

Scientific and AI-generated results

You must fully verify the correctness of obtained results using human researcher competence. Always ask AI how it comes to a conclusion. Require SQL queries, used formulas and literature sources. If obtained SQL is difficult to interpret, ask the SIS team for assistance. Data, calculations and AI-generated explanations can contain errors. This is a research only tool and should not be used for other purposes.
