Privacy notice

ETHZ SIS group operates the DynaProt Structural Proteomics Atlas (DSPA). Contact audrius.meskauskas@ethz.ch with questions or requests about personal data.

This notice covers the website at dynaprot.org and the DSPA MCP service, including access through the DSPA agent in Microsoft 365 Copilot.

Information we process and why

  • MCP sign-in: the existing ETH Zurich/Microsoft Entra provider authenticates you. This server has no access to your login credentials. We have access to id uniquely tied to your account.
  • Research requests: MCP currently logs SQL queries, but not your questions or Copilot answers. If you need more confidentiality, contact us to turn the logging off.
  • Memory: MCP has a per-user memory tool that can store, read, and forget memory entries. Storing and deletion happens after your approval. If the memory feature disturbs you, contact us to turn the memory off. You can delete wrong entry by asking Copilot to do so.
  • Uniprot: MCP server has the Uniprot tool that can make requests to Uniprot. The data of your request then will become subject of Uniport privacy policy. While they claim they do not log the content of the query, do not enter any data that this sharing is not acceptable for. If necessary, contact us to disable the Uniprot tool.
  • Other web:DSPA MCP is behind the whitelist firewall and cannot contact arbitrary web servers.

This service is intended for professional usage within the research scope only. Do not supply any sensitive personal data. Never tell any passwords, authentication keys, or anything the like to Copilot.

In case critical sensitive information is leaked, contact us immediately to wipe all persistent data.
